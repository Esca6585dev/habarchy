# 0796 (operator SMPP) arkaly SMS / OTP ugratmak

**TK:** Bu gollanma türkmen operatorynyň SMPP şlýuzy (meselem `0796` gysga
belgisi) bilen Habarçydan SMS we OTP ibermegi düşündirýär. Operator saňa
şeýleräk maglumat berýär (nusga):

```
SMPP_IP=119.235.115.204
SMPP_PORT=15019
SMPP_FROM=0796
SMPP_USERNAME=Tstandart
SMPP_PASSWORD=********      # gizlin — repozitoriýa salma
```

> ⚠️ Bu maglumat **gizlin**. Ony git-e, screenshot-a ýa-da umumy çata salma.
> Diňe serweriň `.env` faýlynda (git-ignored) ýa-da secret store-da sakla.
> Habarçy ony bazada **AES-256-GCM** bilen şifrläp saklaýar.

## Maglumatlaryň gabat gelşi

| Operatoryň berýäni | → | Habarçy SMPP meýdany |
|--|--|--|
| `SMPP_IP` | → | `host` |
| `SMPP_PORT` | → | `port` |
| `SMPP_USERNAME` | → | `system_id` |
| `SMPP_PASSWORD` | → | `password` |
| `SMPP_FROM` (0796) | → | `source_addr` (ugradyjy / gysga belgi) |

## 1-nji ädim — baglanyşygy barlamak (`smpptest`)

SMS ibermezden ozal, login (bind) işleýärmi barla. Şuny **operatoryň IP-sine
ýetip bilýän** maşynda işlet (serwer ýa-da operatoryň rugsat beren tory):

```sh
cd backend
export SMPP_IP=119.235.115.204 SMPP_PORT=15019 \
       SMPP_USERNAME=Tstandart SMPP_PASSWORD='...' SMPP_FROM=0796

go run ./cmd/smpptest                      # diňe bind: login işleýärmi
go run ./cmd/smpptest -to 65656585 -text "Habarçy synag"   # bind + 1 SMS
go run ./cmd/smpptest -to +99365656585 -dlr                # gowşuryş hasabatyna hem garaş
```

- `✓ bind OK` — login kabul edildi.
- `✓ submitted: provider_message_id=…` — SMS SMSC-e tabşyryldy.
- Türkmen/kiril tekst awtomat **UCS2** bilen gidýär, uzyn tekst bölünip
  birikdirilýär (UDH). Bare nomer (`65656585`) `+99365656585` diýip okalýar.

## 2-nji ädim — Habarçyda provider döretmek

### Ýol A — `.env` + seed (iň çalt)

`backend/.env`-e ýokardaky `SMPP_*` setirleri goş, soň:

```sh
cd backend
go run ./cmd/api -seed -seed-live-key
```

Seeder `Operator SMPP` atly **işjeň (active) smpp provider** döredýär,
`otp` şablonyny (tk/ru/en) ýükleýär we bir `hb_live_…` açary çap edýär.
Ikinji gezek işletseň täzeden döretmeýär (idempotent).

### Ýol B — admin panelden

Admin panel → **Providers → Add provider** → görnüş `smpp` →
`host`, `port`, `system_id`, `password`, `source_addr=0796` → **Save**.
Soň provideri açyp **Test** basyp barlap bolýar.

## 3-nji ädim — OTP / SMS ugratmak

```sh
# OTP kody (0796-dan gidýär)
curl -X POST $HABARCHY/api/v1/otp/send \
  -H "X-Api-Key: hb_live_xxx" -H 'Content-Type: application/json' \
  -d '{"channel":"sms","to":"+99365656585"}'

# Kody barlamak
curl -X POST $HABARCHY/api/v1/otp/verify \
  -H "X-Api-Key: hb_live_xxx" -H 'Content-Type: application/json' \
  -d '{"to":"+99365656585","code":"482193"}'

# Ýönekeý SMS
curl -X POST $HABARCHY/api/v1/messages \
  -H "X-Api-Key: hb_live_xxx" -H 'Content-Type: application/json' \
  -d '{"channel":"sms","to":"+99365656585","body":"Salam! Habarçy işleýär."}'
```

OTP kody hiç ýerde log edilmeýär, Redis-de diňe hash görnüşinde saklanýar,
adres/IP boýunça rate-limit bar.

## 4-nji ädim — "kim kime näme ugratdy" (dolandyryş)

- **API:** `GET /api/v1/messages?channel=sms&status=&from=&to=` — ugradylan
  SMS-leriň sanawy; `GET /api/v1/messages/{id}` — status + timeline.
- **Admin panel:** *Messages log* — süzgüçler (status, sene, gözleg),
  her habaryň jikme-jigi (timeline + SMSC jogaby), gaýtadan ugratmak (resend).
- **Admin API:** `GET /api/admin/projects/{id}/messages?...` we
  `GET /api/admin/projects/{id}/dashboard?days=` — günlük statistika.

## Bellikler

- Birnäçe provider goýup bolýar (prioritet boýunça fallback): meselem 0796
  SMPP esasy, telefon-SIM (android_sms) ätiýaçlyk.
- `request_dlr=true` goýsaň, SMSC gowşuryş hasabatyny (DLR) iberýär we habaryň
  statusy `delivered` bolýar.
- Nomerler taslamalar (project) boýunça aýrylýar — bir müşderiniň nomerleri
  başgasyňka garyşmaýar.
